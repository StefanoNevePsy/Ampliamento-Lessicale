Terapia Attiva v40

Piattaforma per la terapia psicoeducativa, il precision teaching e la riabilitazione neuropsicologica. Gestisci pazienti, crea set personalizzati e monitora i progressi con strumenti clinici avanzati.

Gestione Pazienti

  • Selettore Rapido: In alto a destra trovi il menu a tendina.
    Seleziona "Ospite" per sessioni senza salvataggio.
  • Cartella Clinica: Clicca per gestire l'anagrafica.
  • Dashboard (3 schede):
    Panoramica - Riepilogo, grafico giornaliero, ultima sessione.
    Giornate - Storico espandibile per data.
    Attività - Grafici di progressione per attività con badge criterio.
  • Criterio (Mastery): Assegnato automaticamente dopo 2 sessioni consecutive con >90% in giorni diversi.
  • Editing Dati: Espandi i grafici () per correggere errori, date o eliminare sessioni.

Modalità (17)

  • TACT: Flashcards sequenziali per denominazione pura.
  • RAN: Denominazione rapida.
    Usa il tasto per passare da vista Griglia a Sequenza.
  • Fluenza: Denominazione a tempo. Scegli la durata (15s-120s o personalizzata), premi Avanti per iniziare il timer. Conta le risposte corrette/errate. Mostra l'obiettivo per la volta successiva (max storico + 2). La barra tempo può essere nascosta per ridurre l'ansia.
  • Tombola: Matching visivo. Trova l'immagine target nella griglia.
  • Tombola Sonora: Ascolta un suono e tocca la carta corrispondente. Richiede audio ().
  • Memory: Gioco di memoria per funzioni esecutive.
  • Cerca Trova: Esplorazione visiva su scene. Tocca per marcare i bersagli.
  • Intraverbal-Scenari: Come Cerca Trova, con dati tracciati separatamente.
  • Zoom: Immagine zoomata su un dettaglio. Il bambino indovina l'intera immagine. Area zoom definibile nell'editor ().
  • Topologia: Trascina le immagini per disporle spazialmente.
  • Sequenze: Ordina le immagini per numero progressivo. Se N.Stimoli < totale, estrae un sottoinsieme casuale. Corretto = ordine crescente (anche non consecutivo).
  • Pool Random: Griglia di stimoli casuali dai tag. N. Stimoli = carte a schermo. Avanza all'infinito.
  • Pool Intraverbal: Come Pool Random, con dati tracciati separatamente.
  • Intruso: Trova l'intruso! N. Stimoli = carte per round. Richiede 2+ tag.
  • Categorizzazione: Assegna ogni immagine alla categoria corretta. Richiede 2+ tag.
  • Quaderno: Registro manuale:
    Generale - Righe di attività con X/Prompt/V.
    Task Analysis - Passi operazionalizzati (X/P/V/N.A.).
    Le liste si salvano come template ricaricabili.

Sessione & Scoring

  • Valutazione: Usa i tasti a schermo o la tastiera.
    V = Corretto (Tasto 'V')
    P = Prompt (Tasto 'P', in Time Delay)
    X = Errato (Tasto 'X')
  • Tipo Sessione:
    Indipendente - Scoring V/X standard.
    Time Delay - Scoring V/P con secondi TD configurabili.
  • N. Stimoli: Scegli quanti stimoli presentare (3, 4, 6, 8... o Tutti).
  • Griglia: Layout visivo (Auto, 3x3, 4x4, 5x5) per modalità a griglia.
  • Child Lock : Blocca lo scroll per evitare tocchi accidentali.
  • Salvataggio : Salva i dati nella cartella del paziente attivo. Puoi inserire un nome personalizzato.

Editor, Libreria & Backup

  • Creazione: Crea set personalizzati caricando le tue immagini.
  • Tag Semantici: Assegna tag (es. "animali", "verbi") per organizzare i set e abilitare le modalità Pool, Intruso e Categorizzazione.
  • Caricamento Rapido:
    - Clicca sull'icona fotocamera .
    - Ctrl+V su una riga per incollare dagli appunti.
    - Bulk: Carica intere cartelle in una volta.
  • Audio (): Carica file audio per ogni item (Tombola Sonora).
  • Zoom Area (): Definisci l'area di zoom per la modalità Zoom.
  • Sequenze (#): Assegna numeri progressivi agli item per la modalità Sequenze.
  • Esporta Singolo Set (): Ogni set ha un pulsante per esportarlo singolarmente (con le immagini dei tag). Ideale per condividere set tra colleghi.
  • Backup Completo: Esporta un unico file con tutti i Set, Pazienti, Tag Images, Template Quaderno e Nomi Sessione.
  • Importa / Sincronizza: L'importazione è non distruttiva:
    - I set e pazienti già presenti vengono aggiornati (nuovi item aggiunti, esistenti aggiornati).
    - Set e dati locali non presenti nel backup vengono mantenuti.
    - Nessun dato viene cancellato.
    - Funziona sia con backup completi che con singoli set esportati.
  • Sync Diretto (): Trasferisci set e dati direttamente tra due dispositivi via connessione peer-to-peer (WebRTC).
    - Un dispositivo preme Invia e mostra un QR code.
    - L'altro preme Ricevi e scansiona il QR (o inserisce il codice).
    - I dati viaggiano direttamente tra i due dispositivi.
    - Ogni set ha anche il pulsante per inviare solo quel set.
    - La sincronizzazione è non distruttiva (merge).
  • Firebase Sync (): Sincronizzazione automatica dei dati pazienti tra dispositivi via Firebase Realtime Database.
Design e Sviluppo per uso Professionale - v40

Firebase Sync

Sincronizza i dati dei pazienti tra dispositivi via Firebase Realtime Database. Solo i dati delle sessioni vengono sincronizzati (non le immagini).

Sync Diretto

Trasferisci set e dati direttamente tra due dispositivi via connessione peer-to-peer. Entrambi devono avere accesso a internet per la connessione iniziale, poi i dati viaggiano direttamente.
