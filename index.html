Terapia Attiva v40

Piattaforma per la terapia psicoeducativa, il precision teaching e la riabilitazione neuropsicologica. Gestisci pazienti, crea set personalizzati e monitora i progressi con strumenti clinici avanzati.

Interfaccia

  • Selettore Attività: Dropdown ricco con icone, colori per categoria e conteggio set compatibili.
  • Selettore Set: Anteprima immagine, conteggio stimoli e badge di stato per paziente:
    Criterio Repertorio Vicino 85%
  • Ordinamento set: Per categoria, nome, % recente, ultimi usati, criterio.
  • Selettore Paziente: Con foto, categorie raggruppate e accesso rapido ai dati.
  • Fullscreen: Premi per lo schermo intero.
  • Child Lock: Blocca scroll/tocchi accidentali durante la seduta.

Gestione Pazienti

  • Foto Paziente: Carica una foto dal selettore o incolla con Ctrl+V. La foto appare nei dropdown e nella cartella.
  • Categorie: Assegna una categoria ai pazienti (es. tipo di intervento). I pazienti appaiono raggruppati nei selettori.
  • Dashboard (3 schede):
    Panoramica – Statistiche giornaliere, grafico LU, ultima sessione.
    Giornate – Storico espandibile per data, con icone modalità e anteprima set.
    Attività – Grafici di progressione con badge criterio, icone modalità e miniatura del set.
  • Criterio (Mastery): 2 sessioni consecutive ≥90% in giorni diversi.
  • Repertorio: Prima sessione in assoluto ≥90%.
  • Export Excel: Esporta i dati del paziente in formato tabellare.

Modalità (17)

  • TACT: Flashcards sequenziali per denominazione pura.
  • RAN: Denominazione rapida. per Griglia/Sequenza.
  • Fluenza: A tempo (15s-120s). Obiettivo = max storico + 2. Barra tempo nascondibile.
  • Tombola: Matching visivo target-griglia.
  • Tombola Sonora: Ascolta e tocca. Richiede audio .
  • Memory: Gioco di memoria per funzioni esecutive.
  • Cerca Trova: Esplorazione visiva su scene con marker.
  • Intraverbal-Scenari: Come Cerca Trova, dati separati.
  • Zoom: Dettaglio zoomato da indovinare. Area definibile nell'editor ().
  • Topologia: Trascina per disposizione spaziale.
  • Sequenze: Ordina per numero progressivo. Sottoinsieme casuale se N.Stimoli < totale.
  • Pool Random: Griglia casuale dai tag. Avanza all'infinito.
  • Pool Intraverbal: Come Pool Random, dati separati.
  • Intruso: Trova l'intruso! 2+ tag richiesti.
  • Categorizzazione: Assegna a categoria corretta. 2+ tag richiesti.
  • Quaderno: Registro manuale (Generale: X/P/V, Task Analysis: X/P/V/N.A.).
    I template si salvano come set nella libreria, modificabili e riordinabili.

Sessione & Scoring

  • Valutazione: Tasti a schermo o tastiera.
    V = Corretto P = Prompt (TD) X = Errato
  • Tipo Sessione:
    Indipendente – Scoring V/X standard.
    Time Delay – Scoring V/P con secondi TD configurabili.
  • Field: Numero di stimoli visibili (3, 4, 6, 8… o Tutti).
  • Griglia: Layout visivo (Auto, 3×3, 4×4, 5×5).
  • Undo: Ctrl+Z per annullare l'ultimo punteggio.
  • Salvataggio: Salva nella cartella del paziente attivo. Nome personalizzabile.
  • S Pen: Singolo clic = V, doppio clic = X (Samsung S Pen).
  • Shortcut: D = Puntatore F = Fullscreen area L = Blocco scorrimento E = Etichette S = Salta round

Editor & Libreria

  • Creazione: Crea set personalizzati caricando immagini, con nome e categoria.
  • Tag Semantici: Assegna tag (es. "animali", "verbi") per le modalità Pool, Intruso e Categorizzazione.
  • Caricamento: Fotocamera , Ctrl+V per incollare, o Bulk per intere cartelle.
  • Audio: Carica file audio per ogni item (Tombola Sonora).
  • Zoom Area: Definisci il dettaglio per la modalità Zoom.
  • Sequenze (#): Numeri progressivi per la modalità Sequenze.
  • Libreria: Ordinamento per categoria, nome, recenti, N.stimoli, modalità. Categorie collassabili. Riordina i set con le frecce .

Personalizzazione Attività

  • Categorie Attività: Raggruppa le modalità in categorie con nome e colore personalizzati.
  • Icone Modalità: Clicca sull'icona di una modalità per scegliere tra 90+ icone Font Awesome. L'icona appare nel selettore e nella cartella clinica.
  • Emoji: Aggiungi un emoji personalizzato per ogni modalità.
  • Attività Personalizzate: Crea attività con nome personalizzato basate su una modalità base (es. "Scena Azioni" basata su Cerca Trova).
  • Riordina: Sposta categorie e modalità con le frecce. Trasferisci attività tra categorie.

Backup & Sincronizzazione

  • Esporta Singolo Set: Con immagini, tag e ordinamento inclusi.
  • Backup Completo: Tutti i set, pazienti, tag images, template, nomi sessione, layout attività (icone, colori, emoji).
  • Importazione: Non distruttiva – set e pazienti aggiornati, dati locali mantenuti, nessuna cancellazione.
  • Quick Share: Condividi set, pazienti o backup completo via Nearby Share / Quick Share / AirDrop. Offline e velocissimo!
    Seleziona → Condividi → Scegli dispositivo vicino. Zero configurazione.
  • Sync Diretto (P2P): Trasferisci via QR code tra dispositivi. Ogni set ha il bottone .
    Invia → QR → Ricevi scansiona → Merge automatico.
  • Firebase Sync: Sincronizzazione automatica dati pazienti tra dispositivi via Firebase Realtime Database.

Firebase Sync

Sincronizza i dati dei pazienti tra dispositivi via Firebase Realtime Database. Solo i dati delle sessioni vengono sincronizzati (non le immagini).

Sync Diretto

Trasferisci set e dati direttamente tra due dispositivi via connessione peer-to-peer. Entrambi devono avere accesso a internet per la connessione iniziale, poi i dati viaggiano direttamente.

I dati vengono compressi e inviati un elemento alla volta, anche per librerie molto grandi.

Condivisione Offline

Trasferisci i dati di un paziente tra dispositivi senza internet. Funziona via QR code animato o condivisione file locale.

Quick Share

Condividi istantaneamente via Nearby Share, Quick Share, AirDrop o Bluetooth. Funziona offline ed è velocissimo.

Come funziona: Seleziona cosa condividere → si apre il pannello di condivisione del sistema → scegli il dispositivo vicino. Nessun internet necessario!
